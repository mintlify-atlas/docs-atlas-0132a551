---
title: "Trellises: grow and decorate with vine plants"
description: "Trellises host growing vine crops or decorative plants on any Bountiful Fares trellis block. The system is data-driven, comparator-aware, and extensible via datapacks."
---

Trellises are thin, wall-like blocks that serve a dual purpose: they can host growing vine crops that you harvest by right-clicking, or they can display decorative plants as aesthetic accents. Both crop types and decorative plants are defined by a data-driven JSON system, making trellises fully extensible through datapacks.

## Obtaining trellises

Trellises are crafted from planks and sticks. Every vanilla wood type has a corresponding trellis variant, as do Bountiful Fares' own wood types:

| Wood type | Source |
|---|---|
| Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove, Cherry, Bamboo | Vanilla planks |
| Walnut | Bountiful Fares Walnut planks |
| Hoary | Bountiful Fares Hoary planks |
| Crimson, Warped | Nether planks |
| Palm | Bountiful Fares Palm planks |

Additional wood types are available when compatible mods are installed (Nature's Spirit, Arts and Crafts, No Man's Land, Frontiers, etc.).

Trellises can be waterlogged and face any of the four horizontal directions when placed.

## Planting and harvesting

<Steps>
  <Step title="Place a trellis">
    Place a trellis block against a wall or as a freestanding structure. It faces the direction opposite to where you clicked.
  </Step>
  <Step title="Plant a crop or decorative plant">
    Right-click the trellis while holding a valid seed item (for crops) or a valid plant item (for decorative plants). The item is consumed and the trellis displays the planted content.
  </Step>
  <Step title="Wait for the crop to grow">
    Trellis crops advance through growth stages on random ticks. Each crop's growth speed is defined by its `grow_chance` field in its JSON definition.
  </Step>
  <Step title="Harvest a ripe crop">
    Once a trellis crop reaches its maximum stage, **right-click** to harvest. The crop drops its produce and regresses by 2 stages, allowing it to regrow. The trellis itself is not broken.
  </Step>
  <Step title="Remove a plant">
    **Left-click (attack)** the trellis to remove whatever is planted on it. The seed or plant item is dropped.
  </Step>
</Steps>

<Tip>
Bone Meal works on both crops and decorative plants. On a crop, it advances the growth stage by one. On a decorative plant with `can_duplicate: true`, it drops an additional copy of the plant item.
</Tip>

## Comparator output

Trellises support redstone comparator output, allowing you to build automatic harvest detectors.

| State | Comparator output |
|---|---|
| Empty | 0 |
| Crop planted, growing | 1–15 (scales with growth stage) |
| Crop at maximum stage | 15 |
| Decorative plant present | 15 (always) |

## Default trellis crops

These trellis crops are included with Bountiful Fares out of the box:

| Crop | Seed item | Produce | Stages | Drop range |
|---|---|---|---|---|
| Passion Fruit | Passion Fruit | Passion Fruit | 4 | 1–3 |
| Elderberry | Elderberries | Elderberries | 4 | 1–3 |
| Lapisberry | Lapisberry Seeds | Lapisberries | 4 | 2–3 |
| Glow Berries | Glow Berries | Glow Berries | 4 | 2–3 |

When Farmer's Delight is installed, **Tomatoes** can also be grown on trellises using Tomato Seeds.

## Default decorative trellis plants

These decorative plants are included with Bountiful Fares out of the box. They display on a trellis and can optionally be duplicated with Bone Meal.

| Plant | Item | Can duplicate |
|---|---|---|
| Rose Bush | Rose Bush | Yes |
| Lilac | Lilac | Yes |
| Peony | Peony | Yes |
| Sunflower | Sunflower | Yes |
| Vine | Vine | No |
| Weeping Vines | Weeping Vines | Yes |
| Twisting Vines | Twisting Vines | Yes |

When Frontiers is installed, Ancient Rose Bush and Violet Rose Bush are also available as decorative trellis plants.

## Data-driven customization

The trellis system is fully data-driven. Datapacks can define new trellis crops and decorative plants using JSON files.

### File locations

Place JSON files in your datapack under the following directories:

```
data/<pack-id>/bountifulfares/trellis_crop/<name>.json   # crop definitions
data/<pack-id>/bountifulfares/trellis_plant/<name>.json  # plant definitions
```

### Trellis crop schema

```json
{
  "seeds": "namespace:item_id",
  "produce": "namespace:item_id",
  "texture": "namespace:block/texture_name",
  "model": "default",
  "stages": 4,
  "grow_chance": 0.2,
  "min_drops": 1,
  "max_drops": 3
}
```

The `model` field accepts `"default"` or `"inverted"`. Use `"inverted"` for plants that grow upward (like Twisting Vines). Textures for each growth stage are located automatically by appending `_0`, `_1`, … `_<stages>` to the texture path.

### Trellis plant schema

```json
{
  "plant": "namespace:item_id",
  "texture": "namespace:block/texture_name",
  "model": "default",
  "can_duplicate": true
}
```

Set `"can_duplicate": true` to allow Bone Meal to drop an additional copy of the plant item.

<Note>
Example datapack files are available in the `example_trellis_plants/` directory of the Bountiful Fares GitHub repository.
</Note>
