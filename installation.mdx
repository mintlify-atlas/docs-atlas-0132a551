---
title: "Install Bountiful Fares on Fabric or NeoForge"
description: "Step-by-step guide to installing Bountiful Fares and its required dependency NexusLib on Fabric or NeoForge for Minecraft 1.21.1 in minutes."
---

Bountiful Fares supports both **Fabric** and **NeoForge** on Minecraft 1.21.1. Before installing the mod, make sure you have the correct mod loader version and the required dependency, NexusLib. Pick your loader below to follow the appropriate steps.

<Warning>
  **Updating from a version before 3.0.0?** This will break trellis blocks with plants attached — break the plants before updating. The Tea Blends and Custard items have also been removed in 3.0.0 and will be deleted from your world.
</Warning>

<Tabs>
  <Tab title="Fabric">
    <Steps>
      <Step title="Install Minecraft 1.21.1">
        Open the Minecraft launcher and install version **1.21.1** from the Installations tab if you haven't already.
      </Step>
      <Step title="Install Fabric Loader 0.18.5 or later">
        Download the Fabric installer from [fabricmc.net](https://fabricmc.net/use/installer/) and run it. Select Minecraft version **1.21.1** and Loader version **0.18.5** or newer, then click **Install**.
      </Step>
      <Step title="Download NexusLib">
        NexusLib is a required dependency. Download version **1.1.4** or later for Fabric from [Modrinth](https://modrinth.com/mod/nexuslib).
      </Step>
      <Step title="Download Bountiful Fares">
        Download the latest Fabric release of Bountiful Fares from [Modrinth](https://modrinth.com/mod/bountiful-fares). Make sure you select the Fabric JAR for Minecraft 1.21.1.
      </Step>
      <Step title="Place both JARs in your mods folder">
        Copy both `nexuslib-*.jar` and `bountifulfares-*.jar` into your `.minecraft/mods` folder. If the folder does not exist, launch Fabric once to create it.
      </Step>
      <Step title="Launch the game">
        Open the Minecraft launcher, select the **Fabric** profile for version 1.21.1, and click **Play**. Bountiful Fares will be active once the game loads.
      </Step>
    </Steps>
  </Tab>
  <Tab title="NeoForge">
    <Steps>
      <Step title="Install Minecraft 1.21.1">
        Open the Minecraft launcher and install version **1.21.1** from the Installations tab if you haven't already.
      </Step>
      <Step title="Install NeoForge 21.1.219 or later">
        Download the NeoForge installer from [neoforged.net](https://neoforged.net/) and run it. Select version **21.1.219** or newer for Minecraft 1.21.1, then click **Install client**.
      </Step>
      <Step title="Download NexusLib">
        NexusLib is a required dependency. Download version **1.1.4** or later for NeoForge from [Modrinth](https://modrinth.com/mod/nexuslib).
      </Step>
      <Step title="Download Bountiful Fares">
        Download the latest NeoForge release of Bountiful Fares from [Modrinth](https://modrinth.com/mod/bountiful-fares). Make sure you select the NeoForge JAR for Minecraft 1.21.1.
      </Step>
      <Step title="Place both JARs in your mods folder">
        Copy both `nexuslib-*.jar` and `bountifulfares-*.jar` into your `.minecraft/mods` folder. If the folder does not exist, launch NeoForge once to create it.
      </Step>
      <Step title="Launch the game">
        Open the Minecraft launcher, select the **NeoForge** profile for version 1.21.1, and click **Play**. Bountiful Fares will be active once the game loads.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Optional compatible mods

These mods are not required but add extra content or integration when used alongside Bountiful Fares:

| Mod | Loader | What it adds |
| --- | ------ | ------------ |
| [AppleSkin](https://modrinth.com/mod/appleskin) | Fabric | Displays food values for items inside Shulker Tiffins correctly |
| [Mod Menu](https://modrinth.com/mod/modmenu) | Fabric | Browse installed mods and access Bountiful Fares config in-game |
| [Nature's Spirit](https://modrinth.com/mod/natures-spirit) | Fabric, NeoForge | Compatibility content added for Nature's Spirit biomes |
| [Amendments](https://modrinth.com/mod/amendments) | Fabric, NeoForge | Cauldron fluid support and cake-eating sounds for mod cakes |
| [Farmer's Delight](https://modrinth.com/mod/farmers-delight) | Fabric, NeoForge | Maize, chamomile, and tomatoes work with Rich Soil Farmland |
| [Arts and Crafts](https://modrinth.com/mod/artsandcrafts) | Fabric, NeoForge | Cross-mod compatibility content |
| [Appledog](https://modrinth.com/mod/appledog) | Fabric, NeoForge | Cross-mod compatibility content |
| [No Man's Land](https://modrinth.com/mod/no-mans-land) | NeoForge | Pine, Maple, Walnut, and Willow trellises; Candied Pears; Maple Mead |
| [Frontiers](https://modrinth.com/mod/frontiers-mod) | Fabric | Trellis plants for Ancient and Violet Rose Bushes; Eboncork trellises |
